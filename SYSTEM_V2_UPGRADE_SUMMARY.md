## 🔧 Agent Algorithm Implementation

### Webster's Algorithm (L1)

**Formula**:
```
g_i = (L + 1.5 * l_i) * (y_i / C - l_s)

Where:
- L = lost time per cycle (default 12s)
- l_i = lost time for phase i
- y_i = traffic yield for phase i  
- C = cycle time (default 90s)
- l_s = total system lost time

Output:
- Green Time: 20-80 seconds
- Red Time: Variable
- Yellow Time: 5 seconds (fixed)
```

### SCATS Adaptation (L2)

**Occupancy-Based Response**:
```
If occupancy > 70%:
  newGreenTime = baseGreenTime × (1 + 0.15 × ((occupancy - 70) / 30))
  
If occupancy < 30%:
  newGreenTime = baseGreenTime × (1 - 0.15 × ((70 - occupancy) / 70))

Result: ±30% variation from baseline
```
